# E-Commerce Data Analysis Using Microsoft Excel

## 1. Project Overview

This project focuses on analyzing an E-Commerce Store dataset using Microsoft Excel to understand sales performance, customer purchasing behaviour, product category trends, regional sales distribution, and business performance.

The project involves data cleaning, data transformation, Excel formulas,  Pivot Tables, descriptive statistics, and interactive dashboard creation to generate meaningful business insights.

## 2. Project Objectives

- Organize and structure raw E-Commerce data using Excel tables.
- Identify and remove duplicate records.
- Handle missing values and inconsistent data.
- Correct formatting errors and validate data.
- Remove irrelevant columns from the dataset.
- Apply Excel formulas for calculations and data analysis.
- Create Pivot Tables for data summarization.
- Perform descriptive statistical analysis.
- Develop interactive dashboards using charts and PivotCharts.

## 6. Key Business Insights

- Insights
•	The state-wise sales analysis shows a total revenue of 86,137.93, with Alabama contributing the highest sales (12,011.54), followed by Florida (10,996.93) and Vermont (10,020.16).
•	The category-wise sales analysis shows a total of 201 sales transactions, with Sports recording the highest number of sales (61), followed by Clothing (38) and Home (36).
•	The region-wise analysis shows that the West region has the highest average sales amount (1,172.02), followed by East (1,123.40) and North (1,105.30), while South records the lowest (1,040.32).
•	The payment method analysis shows a total of 683 transactions, with PayPal being the most preferred payment method (239 transactions), followed by COD (229) and Credit Card (215).
•	The yearly sales analysis shows a significant increase in revenue from 75,727.20 in 2023 to 380,711.56 in 2024, followed by a decrease to 294,292.31 in 2025.
•	2023 to 2024: Revenue increased by 402.7%.
•	2024 to 2025: Revenue decreased by 22.7%
•	The sales channel analysis shows that Online sales recorded the highest quantity (290), followed by Flagship stores (259) and Outlets (134), out of 683 total transactions.
